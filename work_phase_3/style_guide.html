Style Guide.

This is the style guide for the handcrafts website created as a concept for the connected communities initiative.


I have divided this style guide into 3 sections based on Don Norman's Emotional Design Levels

Visceral


Designing for first impressions covering information architecture, layout, typography and color.

Behavioural


Designing for functionality covering key interactive components including forms wit a focus om micro-interactions and feedback.

Reflective


Designing for meaning and identity covering how users see themselves in the website including ethical considerations.
