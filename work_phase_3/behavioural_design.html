Behavioural Design.

The focus of this section of the Style Guide is ensuring the user needs for usability and function are supported.


Links Navigation Cards Icons Buttons Forms

Link Styles

Link text is styled in blue to clearly stand out from regular content, supporting both accessibility and clarity by helping users quickly recognise clickable elements. A hover effect provides visual feedback, making interactivity clear even for users with limited technical skills. Footer links like "About Us," "FAQ," and "Contact Us" use a soft grey with a distinct hover style, improving visibility and supporting users with limited English proficiency.

Menus and Navigation

The desktop navigation uses clear labels and a downward arrow icon to show that menus contain more links. A hover effect changes the background from black to yellow, offering visual feedback. This supports accessibility by helping users including non-native English speakersม easily identify and interact with key navigation elements.

Navigation mock-up showing menu layout and hierarchy

Card Components

In the gallery page, card components are used to display images that act as clickable links to more detailed content. A hover effect appears when users move the mouse over each image, signaling interactivity and encouraging exploration. Each card includes a short heading underneath the image, clearly indicating what type of content users can expect after clicking. This design enhances clarity and affordance, making it easy for users to understand where they can click and what information they will find.

Icon Set

Icons are used to support understanding in buttons and navigation. The design maintains consistency in shape, weight and meaning.

This icon set is designed to be simple and easy to use, featuring a familiar magnifying glass icon to help users quickly recognize and access the search function across both desktop and mobile. The icon is paired with the word “Search” to support accessibility, especially for users who are not native English speakers, making it easier for them to understand and use the feature with confidence.

Interactive Buttons


Button is designed to makes the text easily readable and is clearly identifiable as clickable through its hover effect. The color change to white on hover indicates that the button triggers an action. The use of high contrast colors and the background change on hover help users visually recognize the button as clickable and it provides immediate visual feedback when users interact with the button. To ensure that they know their action has been acknowledged.

This button is designed to be highly visible and easily identifiable as the most important action on the page. It uses a bold color (green) to attract attention and make it stand out. The hover effect changes the background color, signaling interactivity, and offering immediate visual feedback that the button is clickable.

"The button is designed with simplicity in mind, featuring a light border or a white background. It does not overpower the layout, giving users a sense of a less important interaction. Although the button appears minimalist, the border, text, or icon help signify its clickable nature. The hover effect provides an additional visual cue, allowing users to recognize that the button is interactive without drawing too much attention. When hovered over, it changes its appearance, providing feedback to the user."

This icon button uses the icon to represent an action for search with out text. This allows users to quickly understand the purpose of the button without needing additional text. The icon itself signifies the action the button performs, and the use of aria-label enhances accessibility. The visual change in color when hovering or clicking provides immediate feedback, confirming that the button is interactive.
